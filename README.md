## About me

I’m a journalist with a growing interest in software development, open-source tools and AI-assisted coding.

Most projects on this profile started with a simple question:

> “Wouldn’t it be useful if this existed?”

Sometimes the answer became a working application. Sometimes it became a learning experience. Usually it became both.
